# Waldemar Bagrowski — IT Portfolio

Version 1 of a professional static portfolio website.

## Files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `cv.pdf` — add your CV here before publishing

## Run locally

Simply double-click `index.html` and it will open in your browser.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn placeholder with your LinkedIn profile URL.
3. Put your CV in this folder and name it `cv.pdf`.
4. Review all public information and remove anything confidential or employer-sensitive.
